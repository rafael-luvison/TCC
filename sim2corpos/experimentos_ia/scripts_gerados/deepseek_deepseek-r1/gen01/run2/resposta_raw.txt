Aqui está o programa Python completo que resolve o problema dos dois corpos com gravitação newtoniana em 2D, utilizando unidades adimensionais com G=1. O programa calcula as posições dos corpos de t=0 até t=17 e imprime os resultados no formato CSV especificado.

```python
import math

# Constantes e condições iniciais
m1 = 1.0
m2 = 0.1
x1_0, y1_0 = -0.090909, 0.0
x2_0, y2_0 = 0.909091, 0.0
vx1_0, vy1_0 = 0.0, -0.095346
vx2_0, vy2_0 = 0.0, 0.953463

# Estado inicial
y0 = [x1_0, y1_0, x2_0, y2_0, vx1_0, vy1_0, vx2_0, vy2_0]

# Parâmetros de simulação
dt = 0.01
passos_por_unidade = 100
tempos_saida = list(range(18))
resultados = []

# Função para calcular derivadas
def derivadas(t, y):
    x1, y1, x2, y2, vx1, vy1, vx2, vy2 = y
    dx = x2 - x1
    dy = y2 - y1
    dist_quad = dx**2 + dy**2
    if dist_quad == 0:
        inv_dist3 = 0.0
    else:
        dist = math.sqrt(dist_quad)
        inv_dist3 = 1.0 / (dist * dist_quad)
    
    ax1 = m2 * dx * inv_dist3
    ay1 = m2 * dy * inv_dist3
    ax2 = -m1 * dx * inv_dist3
    ay2 = -m1 * dy * inv_dist3
    
    return [vx1, vy1, vx2, vy2, ax1, ay1, ax2, ay2]

# Método Runge-Kutta de 4ª ordem
def passo_rk4(t, y, deriv_func, h):
    k1 = deriv_func(t, y)
    y_temp = [y[i] + 0.5*h * k1[i] for i in range(len(y))]
    k2 = deriv_func(t + 0.5*h, y_temp)
    y_temp = [y[i] + 0.5*h * k2[i] for i in range(len(y))]
    k3 = deriv_func(t + 0.5*h, y_temp)
    y_temp = [y[i] + h * k3[i] for i in range(len(y))]
    k4 = deriv_func(t + h, y_temp)
    
    y_next = []
    for i in range(len(y)):
        delta = (h/6.0) * (k1[i] + 2*k2[i] + 2*k3[i] + k4[i])
        y_next.append(y[i] + delta)
    return y_next

# Execução da simulação
estado_atual = y0.copy()
t = 0.0
resultados.append([t, estado_atual[0], estado_atual[1], estado_atual[2], estado_atual[3]])

for passo_completo in range(1, 18):
    for subpasso in range(passos_por_unidade):
        estado_atual = passo_rk4(t, estado_atual, derivadas, dt)
        t += dt
    resultados.append([t, estado_atual[0], estado_atual[1], estado_atual[2], estado_atual[3]])

# Saída em formato CSV
print("t,x1,y1,x2,y2")
for linha in resultados:
    t_val, x1, y1, x2, y2 = linha
    print(f"{t_val:.6f},{x1:.6f},{y1:.6f},{x2:.6f},{y2:.6f}")
```

Este programa:
1. Define as condições iniciais e constantes físicas
2. Implementa o método Runge-Kutta de 4ª ordem para integração numérica
3. Calcula as trajetórias dos corpos de t=0 até t=17 com passo temporal de 0.01
4. Armazena as posições a cada unidade de tempo inteira
5. Imprime os resultados no formato CSV exigido, com 18 linhas de dados mais o cabeçalho
6. Formata os números com 6 casas decimais para precisão adequada

A saída será na seguinte estrutura:
```
t,x1,y1,x2,y2
0.000000,-0.090909,0.000000,0.909091,0.000000
1.000000, ... 
...
17.000000, ...
```
